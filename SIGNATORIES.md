# Signatories

Add yourself by pull request, one line per entry, or [open an issue](https://github.com/onedayforhumanity/onedayforhumanity/issues/new?template=sign.yml)
if you do not use git and a maintainer will add you. The "Manifesto" column is the version you
signed; versions are listed in [CHANGELOG.md](CHANGELOG.md). This list is rendered on the
manifesto page of the site at every deployment; the two template rows are skipped. Remove
yourself the same way, by pull request. Git keeps every version of this file, so a deleted line
stays in the history.
